# RepoRecall

> Постоянная память для AI-агентов, хранящаяся там, где вы её контролируете.

RepoRecall — локальный, независимый от модели слой памяти для coding agents. Долговечные записи хранятся в читаемых Markdown-файлах и синхронизируются вместе с проектом через Git. SQLite используется только как удаляемый локальный поисковый индекс.

Репозиторий реализуется вертикальными срезами. Публичный статус находится в [CHANGELOG.md](CHANGELOG.md), а архитектурные решения — в [docs/ru/architecture.md](docs/ru/architecture.md).

## Статус

Ранняя разработка v0.1. API до первого стабильного релиза может меняться.

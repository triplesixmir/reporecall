# Code of Conduct

RepoRecall is built by people with different backgrounds and experience levels. We expect contributors to be respectful, constructive, and inclusive.

Unacceptable behavior includes harassment, discrimination, doxxing, threats, hostile personal attacks, sexualized attention without consent, and deliberately publishing someone else’s private information.

When a concern is reported, maintainers will review it fairly, protect the privacy of people involved where practical, and may remove comments, reject contributions, or restrict participation when behavior harms the community.

If this project has not yet published a dedicated contact address, report a concern privately to the repository maintainers rather than opening a public issue.

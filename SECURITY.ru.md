# Политика безопасности

Не раскрывайте sensitive vulnerabilities в публичном issue. После публикации репозитория используйте настроенный private security channel. До этого свяжитесь с maintainers приватно через канал, указанный вместе с release.

В сообщении укажите затронутую версию или commit, минимальное воспроизведение, влияние проблемы и известный способ mitigation. Удалите из сообщения credentials, private memories, tokens и пути конкретной машины. Не прикладывайте настоящий brain или настоящий `CODEX_HOME`.

RepoRecall работает с потенциально чувствительными memories и не гарантирует обнаружение каждого secret. Проверяйте сгенерированные memories перед commit, используйте private Git remotes для private memory и никогда не сохраняйте credentials намеренно.

Сейчас у проекта нет гарантированного времени ответа или bounty-программы. Maintainers по возможности подтвердят получение отчёта и согласуют disclosure после исправления или mitigation.

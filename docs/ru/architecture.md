# Архитектура

RepoRecall хранит долговечную память в небольших Markdown-файлах с версионируемым YAML frontmatter. Локальная база SQLite индексирует эти файлы для полнотекстового поиска и фильтрации, но её всегда можно удалить и пересоздать.

Ядро не зависит от конкретного поставщика моделей. MCP, Codex и будущие адаптеры агентов используют одно и то же хранилище и Context Builder.
